## B. Конфетный подотрезок
[[Решение]](comp7_b_9.0_2026.py)

В ряд выложено $n$ конфет. У каждой конфеты есть тип $p_i$​. Можно выбрать последовательность подряд идущих конфет с одним условием — в этой последовательности должно быть ровно два различных типа конфет.

Определите максимальное количество конфет, которое можно взять.


#### Формат ввода
В первой строке вводится одно натуральное число $n$ ($1\leq n\leq 10^6$) — количество конфет.
Во второй строке вводится $n$ целых чисел $p_i$ ($1\leq n\leq 10^9$), где $p_i$ тип $i$-й конфеты.

#### Формат вывода
Выведите максимальное количество конфет, которое можно взять.


#### Примеры
| Ввод | Вывод |
| ---- | ----- |
| 6<br>3 3 1 2 2 1 | 4 |
| 2<br>1 1 | 0 |
