## B. Парные k-префиксы
[[Решение]](comp4_b_9.0_2026.py)

Есть $n$ слов одинаковой длины. Необходимо найти такое наибольшее число $k$, чтобы можно было разбить слова на пары так, чтобы у каждой пары слов совпадало хотя бы $k$ первых букв.

Определите максимальное значение $k$.


#### Формат ввода
В первой строке вводится целое число $n$ — количество слов ($1\leq n\leq 2\times 10^5$, $n$ – чётное).

В следующих $n$ строках заданы слова. Гарантируется, что все слова имеют одинаковую длину и суммарная длина слов не превышает $2\times 10^6$.


#### Формат вывода
В единственной строке выведите число $k$ — искомое максимальное значение.


#### Примеры
| Ввод | Вывод |
| ---- | ----- |
| 2<br>bbbb<br>aabc<br>aacc<br>bbbd | 2 |
| 2<br>a<br>b | 0 |
