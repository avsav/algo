## A. Настольный баскетбол
[[Решение]](comp4_a_9.0_2026.py)

В музее игровых автоматов есть старый настольный баскетбол. В него играют $n$ человек. Есть два кольца, каждый игрок может забить мяч в любое из них и получить за это одно, два или три очка.

Счёт в игре представляет собой два числа — сколько очков было получено за попадания в первое и во второе кольцо соответственно. Очки разделяются двоеточием. Например, "30:41 Vasya".

Определите, кто из игроков набрал больше всего очков.


#### Формат ввода
В первой строке записано число $n$ ($1\leq n\leq 50$) – количество игроков.

В следующих $n$ строках записаны имена игроков $s_i$ ($1\leq |s_i|\leq 15$). Имена состоят только из больших и маленьких букв латинского алфавита.

В строке с номером $n + 2$ дано число $m$ ($1\leq m\leq 500$) – количество записей счета.


#### Формат вывода
Выведите через пробел имя игрока, который набрал больше всех очков, и количество очков, которые он набрал. При наличии нескольких ответов разрешается вывести любой.

В следующих $m$ строках даны записи в виде $\" a_i:b_i t_i \"$ без кавычек, где $a_i$ – очки, забитые в первое кольцо, $b_i$ – во второе, $t_i$ – имя игрока, сделавшего счёт таким. Гарантируется, что записи верны.

Начальный счет 0:0.


#### Примеры
| Ввод | Вывод |
| ---- | ----- |
| 3<br>Vasya<br>Petya<br>Masha<br>4<br>3:0 Vasya<br>3:2 Petya<br>4:2 Masha<br>7:2 Masha | Masha 4 |




## B. Парные k-префиксы
[[Решение]](comp4_b_9.0_2026.py)

Есть $n$ слов одинаковой длины. Необходимо найти такое наибольшее число $k$, чтобы можно было разбить слова на пары так, чтобы у каждой пары слов совпадало хотя бы $k$ первых букв.

Определите максимальное значение $k$.


#### Формат ввода
В первой строке вводится целое число $n$ — количество слов ($1\leq n\leq 2\times 10^5$, $n$ – чётное).

В следующих $n$ строках заданы слова. Гарантируется, что все слова имеют одинаковую длину и суммарная длина слов не превышает $2\times 10^6$.


#### Формат вывода
В единственной строке выведите число $k$ — искомое максимальное значение.


#### Примеры
| Ввод | Вывод |
| ---- | ----- |
| 2<br>bbbb<br>aabc<br>aacc<br>bbbd | 2 |
| 2<br>a<br>b | 0 |
