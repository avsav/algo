## A. Размещение доминошки
[[Решение]](comp1_a_9.0_2026.py)

Дано клетчатое поле размером $m\times n$. Некоторые клетки поля заняты. Определите, сколькими способами можно положить доминошку размером 
$2\times 1$ (её можно также повернуть на 90 градусов), так, чтобы ни одна клетка доминошки не располагалась в занятой клетке.

#### Формат ввода
Первая строка содержит два целых числа $n$ и $m$. Каждая из следующих $n$ строк содержит по $m$ символов. Символ "#" означает, что соответствующая клетка занята, а символ "." — что она свободна.

#### Формат вывода
Выведите число способов размещения доминошки.

#### Примеры
| Ввод | Вывод |
| ---- | ----- |
| 2 3<br>...<br>... | 7 |
| 3 4<br>..#.<br>#..#<br>..#. | 5 |
|5 8<br>........<br>.##..##.<br>........<br>#......#<br>.######.| 34 |




## B. Стоячая волна
[[Решение]](comp1_b_9.0_2026.py)


#### Формат ввода
Профессор исследует теорию струн. Он выбрал очень длинную струну и разбил её на участки, которые пронумеровал от 1 до $10^9$.
Изначально высота струны на всех участках была равна нулю. После этого произошло $n$ квантовых событий.

Квантовое событие с номером $i$i имело силу $x_i$ и действовало на участки струны с $l_i$-го по $r_i$-й включительно. В результате этого события высота участка номер $l_i$ увеличилась на $xi$, высота участка номер $l_i+1$ уменьшилась на $x_i$, следующего — снова увеличилась, и так далее до участка номер $r_i$, включительно.

Зная всю информацию о всех $n$ событиях, профессор хочет узнать установившуюся в итоге высоту некоторых интересующих его $m$ участков.

#### Формат вывода
Для каждого из $m$ запросов выведите одно целое число — высоту соответствующего участка.


#### Примеры
| Ввод | Вывод |
| ---- | ----- |
| 2 3<br>...<br>... | 7 |
| 3 4<br>..#.<br>#..#<br>..#. | 5 |
|5 8<br>........<br>.##..##.<br>........<br>#......#<br>.######.| 34 |
