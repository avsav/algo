## A. Размещение доминошки
[[Решение]](comp1_a_9.0_2026.py)

Дано клетчатое поле размером $m\times n$. Некоторые клетки поля заняты. Определите, сколькими способами можно положить доминошку размером 
$2\times 1$ (её можно также повернуть на 90 градусов), так, чтобы ни одна клетка доминошки не располагалась в занятой клетке.

#### Формат ввода
Первая строка содержит два целых числа $n$ и $m$. Каждая из следующих $n$ строк содержит по $m$ символов. Символ "#" означает, что соответствующая клетка занята, а символ "." — что она свободна.

#### Формат вывода
Выведите число способов размещения доминошки.

#### Примеры
| Ввод | Вывод |
| ---- | ----- |
| 2 3<br>...<br>... | 7 |
| 3 4<br>..#.<br>#..#<br>..#. | 5 |
|5 8<br>........<br>.##..##.<br>........<br>#......#<br>.######.| 34 |
