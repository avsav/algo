## A. Поиски ровера
[[Решение]](comp5_a_9.0_2026.py)

Ровер-доставщик выехал из точки 0 в начале проспекта (проспект это прямая). В какой-то момент спутниковая навигация отключилась и точное положение ровера (точка $X$) оказалась неизвестной.

По сигналу с $n$ базовых станций мобильной сети удалось определить $n$ пар чисел: $x_i$, $d_i$, означающих, что базовая станция в точке $x_i$ находится от положения ровера $X$ на расстоянии не более чем $d_i$.

Определите наибольшее возможное значение $X$.


#### Формат ввода
В первой строке вводится одно натуральное число $n$ ($1\leq n\leq 10^5$).

В следующих $n$ строках вводятся по два целых числа $x_i$, $d_i$ ($1\leq x_i, d_i\leq 10^5$).


#### Формат вывода
В единственной строке выведите наибольшее $X$, удовлетворяющее всем показаниям сигналов с базовых станций, либо -1, если не существует $X$, удовлетворяющего всем показаниям.


#### Примеры
| Ввод | Вывод |
| ---- | ----- |
| 2<br>1 2<br>3 2 | 3 |
| 3<br>2 2<br>6 2<br>8 1 | -1 |
| 5<br>100 97<br>115 104<br>97 115<br> 111 115<br>107 97 | 197 |




## B. Непересекающиеся подстроки
[[Решение]](comp5_b_9.0_2026.py)

Дана строка $s$, состоящая из строчных латинских символов. Необходимо найти в ней подстроку, у которой существует максимальное количество непересекающихся вхождений в строку $s$. Вхождением подстроки $t$ в строку $s$ будем называть пару индексов $(l, r)$, такую, что $l\leq r$ и подстрока строки $s$ с $l$ по 
$r$ символ включительно равна строке $t$. Непересекающимися будем называть два вхождения $(l_1, r_1)$ и $(l_2, r_2)$, такие, что отрезок $[l_1, r_1]$ не пересекается с отрезком $[l_2, r_2]$.

Найдите максимальную длину подстроки, удовлетворяющей условию.


#### Формат ввода
Дана строка $s$ ($1\leq |s|\leq 10^5$), состоящая только из строчных латинских букв.


#### Формат вывода
Выведите максимальную длину подстроки, удовлетворяющей условию.


#### Примеры
| Ввод | Вывод |
| ---- | ----- |
| abacaba | 1 |
| abab | 2 |


#### Примечание
В первом примере такой строкой является строка "a".

Во втором примере такой строкой является строка "ab".
