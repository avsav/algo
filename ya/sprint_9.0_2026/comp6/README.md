## A. Большое и кратное трем
[[Решение]](comp6_a_9.0_2026.py)

Нужно из набора цифр составить наибольшее возможное число, которое будет делится на три без остатка. При этом, число может начинаться с ведущих нулей, 
и при равных значениях большим считается более длинное. Например, "00021" считается большим, чем "021".


#### Формат ввода
Вводится строка, состоящая из цифр от $0$ до $9$ — набор цифр. Длина строки не меньше трех и не превосходит $10^5$.


#### Формат вывода
Выведите наибольшее число, которое можно составить из данных цифр, чтобы оно делилось на три без остатка. Гарантируется, что это возможно.


#### Примеры
| Ввод | Вывод |
| ---- | ----- |
| 105 | 510 |
| 2222 | 222 |
| 000 | 000 |
| 54321 | 54321 |




## B. Не в своей тарелке
[[Решение]](comp6_b_9.0_2026.py)

На обед в китайский ресторан пришли $n$ гостей, занумерованных числами от $1$ до $n$, и сели за круглый стол. Изначально шеф-повар подготовил для 
$i$-го гостя блюдо с номером $a_i$, при этом все блюда различны и занумерованы числами от $1 до $n$.
У i-го гостя аллергия на блюдо с номером $i$. К счастью, стол в китайском ресторане круглый и вращающийся (этот стол вращается только в одну сторону). За одну операцию можно повернуть его так, что блюдо, стоявшее у гостя с номером $n$ окажется у гостя с номером 1. У всех остальных гостей, кроме первого, окажется блюдо, ранее стоявшее у гостя с номером на один меньше.

Определите минимальное количество операций необходимое для того, чтобы ни один гость не получил блюда, на которое у него аллергия.


#### Формат ввода
В первой строке задано целое число $n$ — количество гостей и блюд ($1\leq n\leq 2\times 10^5$).
Во второй строке задано $n$ различных целых чисел $a_1,a_2,\ldots,a_n$, где $a_i$ номер блюда, которое приготовил шеф-повар для $i$-го гостя ($1\lew a_i\leq n$, если $i\neq j$, то $a_i\neq a_j$).


#### Формат вывода
Выведите единственное число $k$ — минимальное число операций поворота стола. Если невозможно повернуть стол так, чтобы ни у одного гостя не было аллергии на его блюдо, выведите число -1.


#### Примеры
| Ввод | Вывод |
| ---- | ----- |
| 5<br>1 4 2 3 5 | 1 |
| 5<br>1 3 5 2 4 | -1 |
