## A. Большое и кратное трем
[[Решение]](comp6_a_9.0_2026.py)

Нужно из набора цифр составить наибольшее возможное число, которое будет делится на три без остатка. При этом, число может начинаться с ведущих нулей, 
и при равных значениях большим считается более длинное. Например, "00021" считается большим, чем "021".


#### Формат ввода
Вводится строка, состоящая из цифр от $0$ до $9$ — набор цифр. Длина строки не меньше трех и не превосходит $10^5$.


#### Формат вывода
Выведите наибольшее число, которое можно составить из данных цифр, чтобы оно делилось на три без остатка. Гарантируется, что это возможно.


#### Примеры
| Ввод | Вывод |
| ---- | ----- |
| 105 | 510 |
| 2222 | 222 |
| 000 | 000 |
| 54321 | 54321 |
