## A. Ахаха
[[Решение]](comp2_a_9.0_2026.py)

Вася пишет бота на основе LLM для знакомства с девушками. Бот будет посылать девушке мем, а в ответ девушка, по идее, должна смеяться. Для повышения качества работы бота необходимо организовать обучение с подкреплением. Для этого нужно оценить самую длинную последовательность из смеха над мемом.

Вася считает, что смех — это последовательность чередующихся букв "a" и "h". Так например, "ahahaha", "hah" и "a" являются смехом, а "abacaba" и "hh" — нет.

Необходимо выделить из строки-ответа девушки самую длинную подстроку, которая является смехом, и вывести ее длину.


#### Формат ввода
В первой строке находится одно натуральное число $n$ ($1\leq n\leq 10^5$). — длина строки с ответом девушки.

Во второй строке находится строка из строчных латинских букв длины $n$ — ответ девушки.


#### Формат вывода
Выведите одно число — наибольшую длину смеха в разговоре.


#### Примеры
| Ввод | Вывод |
| ---- | ----- |
| 5<br>ahaha | 5 |
| 24<br>ahahrunawayahahsofasthah | 4 |
| 10<br>ahahaahaha | 5 |




## B. Упаковка простыни
[[Решение]](comp2_b_9.0_2026.py)

Длины сторон простыни равны $n$ и $m$ сантиметрам. Ее необходимо упаковать в плоский пакет прямоугольной формы, длины сторон которого равны $h$ и $w$ сантиметрам.

Простыню можно складывать пополам по горизонтали или вертикали, это можно сделать несколько раз. Кроме того, простыню можно повернуть на 90 градусов. Стороны сложенной простыни должны быть параллельны сторонам пакета, а размеры сложенной простыни в соответствующих измерениях не должны превышать размеры пакета.

Определите минимальное число складываний простыни, необходимое для того, чтобы она помещалась в пакет.


#### Формат ввода
В единственной строке вводятся четыре натуральных числа $n$, $m$, $h$ и $w$ — длины сторон простыни и пакета, соответственно ($1\leq n,m,h,w\leq 10^{18}$) 


#### Формат вывода
Выведите минимальное необходимое количество складываний.


#### Примеры
| Ввод | Вывод |
| ---- | ----- |
| 10 20 20 10 | 0 |
| 3 3 2 2 | 2 |
