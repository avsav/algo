## B. Треугольник
[[Решение]](hw1_b_1.0_2021.py)

Даны три натуральных числа. Возможно ли построить треугольник с такими сторонами. Если это возможно, выведите строку YES, иначе выведите строку NO.<br>
Треугольник — это три точки, не лежащие на одной прямой.

#### Формат ввода
Вводятся три натуральных числа.

#### Формат вывода
Выведите ответ на задачу.

#### Примеры
| Ввод | Вывод |
| ---- | ----- |
| 3 4 5 | YES |
| 3 5 4 | YES |
| 4 5 3 | YES |




## B. Треугольник
[[Решение]](hw1_i_1.0_2021.py)

За многие годы заточения узник замка Иф проделал в стене прямоугольное отверстие размером $D\times E$. Замок Иф сложен из кирпичей, размером 
$A\times B\times C$. Определите, сможет ли узник выбрасывать кирпичи в море через это отверстие, если стороны кирпича должны быть параллельны сторонам отверстия.

#### Формат ввода
Вводятся три натуральных числа.

#### Формат вывода
Выведите ответ на задачу.

#### Примеры
| Ввод | Вывод |
| ---- | ----- |
| 3 4 5 | YES |
| 3 5 4 | YES |
| 4 5 3 | YES |
